## 方法要点（本次新增/修正）

1. **跨单元入口**：`Target.createTarget(READER + #/courseware/uN/uNg2)` —— 新建标签+深路由，
   不要在旧标签 Page.navigate；入口失败用「章节 ID 校验 + 3 次重试」。
2. **题块配方（100 分）**：占位提交 → 读「答案」区 `(k)\n词` 配对 → **去括号备用式**
   （`milpa(milpa farming)`→`milpa`）→ 重新作答 → native setter 精确键入 → 提交。
   - 判分是**精确字符串匹配**；0 分块保持可编辑（直接覆盖重交），部分分才有「重新作答」。
3. **懒渲染**：题块只在进入视口时挂载；必须逐块 scroll+轮询，章节页不会一次渲染全部。
4. **无进度按钮**：视频=拖 progress 到末尾并 dispatch timeupdate；正文=匀速慢滚由阅读器自动 finishNode。
5. **会话**：长链必须带「SSO 跳转检测 + 自动重登」；CDP ws 连接要加超时防挂死。
6. **百分比目录树**：树只显示 0<pct<100 的小节百分比；可用作「按小节攻坚」的目标选择，
   但目录树跟随当前单元缓存，跨单元前必须先校验章节 ID。
